# Folia Portal Fix

Фикс краша `IllegalStateException: World mismatch` в Folia при телепортации жителей через порталы в ад/энд.

## Что не работало

Folia — это сервер Minecraft с многопоточностью, где каждый мир крутится на отдельном потоке. Когда житель (или другая сущность с мозгом) телепортируется через портал в другой мир, происходит такое:

1. В мире-назначении создаётся новая сущность
2. Конструктор вызывает `makeBrain()` → `updateActivityFromSchedule()` → `Level.getCurrentWorldData()`
3. `getCurrentWorldData()` проверяет что текущий поток принадлежит миру этой сущности
4. Но конструктор вызывается на потоке мира-источника, а `level` уже указывает на мир-назначение
5. Проверка падает и кидает `IllegalStateException: World mismatch`
6. Сервер крашится

Это баг самого ядра Folia. Я создал issue: https://github.com/PaperMC/Folia/issues/457

## Как пофиксил

Заплатил метод `Level.getCurrentWorldData()` — вместо краша при несовпадении миров он теперь просто возвращает доступные данные. Это безопасно, потому что:

- "Чужие" данные используются только в момент конструктора новой сущности
- Сразу после конструктора вызывается `restoreFrom()`, который копирует мозг из старой сущности в новую и полностью перезаписывает всё
- Некорректные данные живут доли миллисекунды и никогда не используются в реальной логике

## Как это работает технически

В paperclip JAR встроен `FoliaFixClassLoader` — кастомный загрузчик классов. При запуске сервера он:

1. Перехватывает загрузку класса `net.minecraft.world.level.Level`
2. Через Javassist заменяет тело `getCurrentWorldData()` — убирает `throw` и ставит `return ret`
3. Загружает пропатченный класс в память

Сам файл серверного JAR на диске **не трогается**. Патч применяется только в оперативной памяти при каждом запуске.

## Установка

Просто замените оригинальный `folia-1.21.11-6.jar` на этот и запустите как обычно:

```
java -Xmx4G -jar folia-1.21.11-6.jar --nogui
```

Никаких доп. файлов, флагов или настроек не нужно.

При запуске в консоли появятся строки что фикс активен:
```
[FoliaFix] Патчим Level.getCurrentWorldData() в памяти...
[FoliaFix] Level.getCurrentWorldData() пропатчен! Краш предотвращён.
```

## Версия

- Folia 1.21.11-6 (build 0795007, от 2025-12-25)
- Java 21+

Когда разрабы Folia пофиксят этот баг в ядре, этот патч будет не нужен и можно будет вернуться на оригинальный JAR.
