# Folia Portal Fix + Channel Limit Fix

Фикс двух критических багов Folia:

1. **Краш `IllegalStateException: World mismatch`** при телепортации жителей через порталы
2. **Зависание сервера** при подключении игрока с большим количеством модов (Fabric)

## Баг 1: Краш при телепортации через порталы

Folia — это сервер Minecraft с многопоточностью, где каждый мир крутится на отдельном потоке. Когда житель телепортируется через портал в другой мир, происходит такое:

1. В мире-назначении создаётся новая сущность
2. Конструктор вызывает `makeBrain()` → `updateActivityFromSchedule()` → `Level.getCurrentWorldData()`
3. `getCurrentWorldData()` проверяет что текущий поток принадлежит миру этой сущности
4. Но конструктор вызывается на потоке мира-источника, а `level` уже указывает на мир-назначение
5. Проверка падает и кидает `IllegalStateException: World mismatch`

Это баг самого ядра Folia. Issue: https://github.com/PaperMC/Folia/issues/457

**Фикс:** Метод `Level.getCurrentWorldData()` пропатчен — вместо краша при несовпадении миров он возвращает доступные данные. Это безопасно, потому что `restoreFrom()` сразу перезаписывает мозг.

## Баг 2: Зависание сервера от Fabric-модов

Когда игрок с Fabric-клиентом и большим количеством модов подключается к серверу, каждый мод регистрирует plugin-канал для связи с сервером. В Folia стоит жёсткий лимит — **128 каналов** на игрока. У игрока с 50+ модами каналов может быть 200-400.

При превышении лимита:
1. `PluginMessageBridgeImpl.addChannel()` кидает `IllegalStateException: Too many channels registered!`
2. Игрока кикает: `Invalid custom payload payload!`
3. Но исключение ломает состояние региона — `TickThread.isTickThreadFor()` зависает навсегда в `ArrayList.contains()`
4. Весь регион спавна перестаёт тикать
5. Никто не может зайти, сервер приходится перезапускать

**Фикс:** Лимит каналов увеличен с 128 до 2048. Этого хватает для 500+ модов.

## Как это работает технически

В paperclip JAR встроен `FoliaFixClassLoader` — кастомный загрузчик классов. При запуске сервера он:

1. Перехватывает загрузку `net.minecraft.world.level.Level` — патчит `getCurrentWorldData()`
2. Перехватывает загрузку `io.papermc.paper.connection.PluginMessageBridgeImpl` — увеличивает лимит каналов

Сам файл серверного JAR на диске **не трогается**. Патчи применяются только в оперативной памяти.

## Установка

Просто замените оригинальный `folia-1.21.11-x.jar` на этот и запустите как обычно:

```
java -Xmx4G -jar folia-1.21.11-x.jar --nogui
```

Никаких доп. файлов, флагов или настроек не нужно.

При запуске в консоли появятся строки что фиксы активны:
```
[FoliaFix] Патчим Level.getCurrentWorldData() в памяти...
[FoliaFix] Level.getCurrentWorldData() пропатчен! Краш предотвращён.
[FoliaFix] Патчим PluginMessageBridgeImpl.addChannel() — увеличиваем лимит каналов 128 -> 2048...
[FoliaFix] PluginMessageBridgeImpl.addChannel() пропатчен! Лимит каналов: 2048.
```

## Версия

- Folia 1.21.11-6 (build 0795007, от 2025-12-25)
- Java 21+

Когда разрабы Folia пофиксят эти баги в ядре, патчи будут не нужны и можно будет вернуться на оригинальный JAR.
